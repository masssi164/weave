# Weave E2E and Acceptance Contract

This directory contains the product-language acceptance spine for Weave.

- `features/` contains Gherkin scenarios.
- `scenario_mappings.json` maps each stable scenario tag to executable evidence
  and labels it as either `live-runtime` or `offline-spec` evidence.
- Runtime evidence is generated by the live-stack workflow as sanitized artifacts.

## Rule

A Weave product claim is release-grade only when the scenario, mapping,
executable test, evidence marker, and evidence mode all agree. Offline/spec
markers prove checked-in contracts; they must not be counted as live runtime
evidence in release-candidate artifacts.

## Local check

From the repository root:

```bash
make acceptance-contract
```

From `client/` directly:

```bash
dart run tool/acceptance_contract.dart guard --root .. --features e2e/features --mapping e2e/scenario_mappings.json
```
