# Agent Runtime ownership

Apply root and Server instructions and the shared Java/Spring standard. This is a future
product domain. Buildability is separate from automatic Files/Calendar/Chat release inclusion.
The model, JPA and provider/security libraries are extracted; remaining runtime services and
controllers are still transitional in the executable. Do not claim release isolation yet.

Keep the pure model framework-free. Retain useful provider/security compiled boundaries and
actual behavioral/architecture tests. Shared Keycloak/session/workload security primitives
must be separated by responsibility before runtime omission, not copied or weakened. Retain
planned functionality without advertising incomplete execution as production-ready.
