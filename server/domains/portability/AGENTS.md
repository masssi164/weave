# Portability ownership

Apply root and Server instructions and the shared Java/Spring standard. Canonical transfer,
loss accounting and persistence belong together here, separate from platform Core. Shared
provider-health/binding contracts remain with their platform responsibility, not this feature.

The extracted model is framework-free; persistence owns transfer and migration evidence.
Remaining migration/report services are transitional in the executable. No populated provider
migration, rollback or release inclusion is established by these libraries. Preserve explicit
apply gates, source retention and owner data; never reset data to make tests pass.
