## Bounded claims

Key upload/query/claim, device signing, to-device delivery, room-key backup, multi-device E2EE recovery, verification and encrypted-room accessibility remain `Guarded`. Explicitly encrypted rooms fail closed; the business-room journey does not qualify E2EE. Unsupported Matrix routes fail explicitly. Independent third-party Matrix interoperability and provider replacement/cutover belong to later profiles or #1498.

This is macOS native evidence. Browser handoff, callback delivery, secure storage and application lifecycle still need separate iOS/Android execution before those platforms are claimed. Selected native providers have no independent downstream authentication session; Synapse/Nextcloud session-loss recovery is unclaimed. Genuine human dogfood acceptance and protected-main delivery remain separate #1481 requirements.
