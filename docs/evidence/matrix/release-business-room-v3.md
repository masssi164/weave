# Matrix business-room profile v3 evidence

This evidence qualifies only the five `Supported` rows in the [Matrix Client-Server support profile](../../reference/matrix-client-server-support-profile.md) for Weave-owned Flutter and OpenClaw clients using an authorized non-E2EE business room. It does not complete #1475 or the #1470 release gate.

## Exact local product run

- Source: `b9786160cdc234f53128c91dd986e40b359ea6f2`; accepted specification corpus: `c726993168651f1109259f9a80cc23117d24a37f`. The profile and checker update changes no product runtime code; rerun the disposable journey on its committed profile revision before accepting that revision for release.
- `./gradlew --no-daemon --max-workers=2 testApp` passed in 9m 14s with a clean checkout, `WEAVE_TEST_APP_PUBLIC_DOMAIN=weave.localhost`, the native macOS runner, local test CA/signing, and `WEAVE_TEST_APP_RELEASE_MCP=true`. The disposable stack was torn down after the run.
- A fresh Keycloak browser Authorization Code + PKCE sign-in opened the native Flutter app. The advertised HTTPS Weave Matrix authority initialized the Rust Matrix SDK with the current member session, without a second Matrix credential. Flutter discovered an authorized business room, sent a message, observed readback, refreshed its token, and restored the same room after an app process and Server/Keycloak/PostgreSQL restart. It then left its own room, lost timeline access, logged out, and observed `401 M_UNKNOWN_TOKEN` for both earlier and refreshed Matrix bearers. Both Flutter integration processes exited zero.
- The same isolated stack ran real OpenClaw 2026.9.8 against the Weave Matrix endpoint and observed business-room send/read. The JVM journey asserted public discovery, `whoami`, membership, sync cursor/readback, Matrix send, outsider read/write denial, and persistence across two collaboration passes. Its selected Chat provider was `weave-native` behind `ChatProviderPort`.
- Support-safe local evidence: `build/test-app/weave-e2e-ae3a43510c9eb940/weave-test-app-evidence.json` (local build output, not committed). It records the exact source/spec commits, selected providers, two collaboration passes, PostgreSQL restart, revocation denial and cleanup. No credential or message content is reproduced here.
